# Credits

EsoChat is an independent solaegis implementation. Feature ideas and UX patterns were informed by existing community addons; **no third-party addon source code is vendored**.

## Chat addons (inspiration)

| Addon | Notes |
|-------|--------|
| **pChat** (Ayantir and contributors) | Display overhaul, history, whisper/mention alerts, per-tab system category patterns; raised max chat size / size persistence ideas |
| **rChat** (Rhyono / pChat fork) | Redundant text removal, name modes, timestamps, strip colors, guild rename, prevent fade |
| **FCOChatTabBrain** | Auto tab switch, last channel per tab, whisper/party alert routing |
| **Chat Window Manager** | Tab/window utility ideas |
| **Chat2Clipboard** | Copy chat lines to clipboard |
| **SmartChatMsg** | Saved messages and channel restore after send |
| **HelloTamriel!** | Login/zone/guild greetings and recruiter helpers |
| **TOM** | Messaging assistant ideas |
| **Chat Input Viewer** | Input character counter color thresholds |
| **ShowLootChat** | Loot messages in chat |
| **CopyTextESO** | Copy text affordances |
