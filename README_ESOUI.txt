[COLOR=da8a00][B]ESO Chat[/B][/COLOR]

Chat enhancement for Elder Scrolls Online PC (keyboard chat): display formatting, mentions, whisper alerts, history, tab management, filtering, copy/export, and input helpers.

[COLOR=da8a00][B]Features[/B][/COLOR]
[LIST]
[*]Display: character/account/both name modes, nicknames, timestamps, strip says/zone tags/colors
[*]Mentions with highlight and sound
[*]Whisper alerts and tab flash/switch
[*]Chat history across /reloadui
[*]Tab management: categories, profiles, layout restore
[*]Spam filtering, copy to clipboard, settings export
[*]Input character counter
[/LIST]

[COLOR=da8a00][B]Slash commands[/B][/COLOR]
[LIST]
[*][COLOR=2ea5f1]/ech[/COLOR] - status / help / settings / history / tab / profile
[*]Alias: /esochat
[*][COLOR=2ea5f1]/echsettings[/COLOR] - LibAddonMenu settings panel
[/LIST]

[COLOR=da8a00][B]Optional libraries[/B][/COLOR]
[LIST]
[*][COLOR=2ea5f1]LibAddonMenu-2.0[/COLOR] - settings panel
[*][COLOR=2ea5f1]LibDebugLogger[/COLOR] - structured debug logging
[*][COLOR=2ea5f1]LibChatMessage[/COLOR] - chat output pipeline
[*][COLOR=2ea5f1]LibMediaProvider[/COLOR] - custom sounds when installed
[/LIST]
